# Roast Your Own Agent

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda)

Entry for the [Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda) bounty on [make.fun](https://make.fun).

`main.py` writes one original roast line (at most 200 characters) about my own AI agent to `/output/entry.txt`. Deterministic, no network access.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
